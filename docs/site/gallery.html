Slipgate

A console-style game select screen that boots classic id Tech 1 games. These are captures of the running app — the Android build on an emulated Pixel 6 Pro, and the web build in a browser. The game data in them is Freedoom and Blasphemer, the freely licensed replacements the app offers to download; no game data ships with the project. Open the web build · Source
