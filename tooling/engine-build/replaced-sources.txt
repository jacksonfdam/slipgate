# The upstream files that talk to SDL, a window system, a sound card or the text-mode setup
# screen. Each has either a replacement in platform/ or no place in a gate, and leaving them out
# is what makes the port a layer rather than a fork. Read by build-engine.sh and by the native
# build, so the two can never disagree about what the platform layer replaces.
#
# d_dedicated.c is the standalone server's entry point and brings its own D_DoomMain and zone
# stubs, which is why it cannot be in a build that has the game's. z_native.c is the malloc-backed
# zone, an alternative to z_zone.c rather than a companion. w_file_win32.c is the Windows file
# backend, and w_file_stdc.c is replaced by the memory-backed one in platform/, because a wasm
# module's filesystem is inside the module and the host cannot put a file into it from outside.
